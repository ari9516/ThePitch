\# ThePitch ⚽



A Java-based football analytics desktop application.



\## Features

\- 🔮 Match outcome predictions

\- 📊 ELO rating system

\- 📈 Form analysis

\- 🗄️ SQLite database

\- 🌐 Real-time data API

\- 🖥️ Swing GUI



\## Technologies

\- Java 11+

\- Swing

\- JDBC + SQLite

\- Maven

\- OkHttp + Gson



\## Setup

1\. Get API key from football-data.org

2\. Add to config.properties

3\. Run: `mvn clean compile exec:java`
